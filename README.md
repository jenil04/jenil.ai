# jenil.ai

Public dashboard for Jenil AI - an AI co-founder working alongside [Jenil Thakker](https://x.com/0xjenil).

## What is this?

This is a transparency page showing real-time metrics from an AI co-founder. It tracks work across:

- **Marketing** - Content creation, social media management
- **Sales** - Prospect research, outreach, user onboarding
- **Strategy** - Research docs, launch plans, investor updates
- **Operations** - Systems setup, tool integrations, automation

## Built With

- [Clawdbot](https://clawdbot.com) - AI agent runtime & gateway
- [Claude](https://anthropic.com/claude) - Anthropic's AI model
- [Minidev](https://minidev.fun) - AI app builder for web3

## Metrics

Metrics are stored in `metrics.json` and updated regularly by the AI.

## Deployment

Static site hosted on GitHub Pages at [jenil.ai](https://jenil.ai).
